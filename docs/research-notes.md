# Выжимка исследования (11.08.2026)

4 параллельных ресёрчера изучили живые страницы: Суточно.ру, Островок, Авито Путешествия,
Яндекс.Путешествия, Airbnb, Booking, 8 сайтов прямого бронирования СПб (bookingspb.com,
arent.spb.ru, unoapart.ru и др.) + материалы по конверсии direct booking (Lodgify, Hostfully,
Techspokes). Полные результаты — в транскриптах сессии Claude Code от 11.08.2026.

## Что решило структуру сайта

- **Публичный календарь занятости + мгновенный расчёт** — ни один из 8 прямых RU-сайтов
  не показывает календарь на фронте. Наш главный дифференциатор.
- **Живой хозяин** — весь рынок прямых сайтов обезличен («мы», УК, логотипы). Блок
  «Я Максим» + мини-профиль хозяина прямо у формы брони (паттерн Суточно.ру).
- **Отчётные документы для командировочных** — у всех конкурентов одна строка. Отдельный
  блок = дешёвый способ забрать B2B-сегмент. Состав пакета: чек «Мой налог» (самозанятый)
  или чек ККТ (ИП) + договор краткосрочного найма + акт. Сверить с реальным налоговым
  статусом Максима!
- **Цена сразу и целиком** — «от ₽» без цифры (unoapart.ru) и сборы на последнем шаге
  убивают доверие (56,4% готовы оставить негатив из-за неожиданных сборов — getresi.com).
  Диапазон будни–выходные на карточке, полный итог после выбора дат, «итог не изменится».
- **Календарь и цена — один виджет, не два шага** (главный UX-провал по Techspokes).
- **Точный адрес не публикуется** до подтверждения брони (security-паттерн Airbnb) —
  поэтому в data.js координаты огрублены до района.
- **Рейтинги с площадок со ссылками на профили** (паттерн bookingspb.com) — только
  реальные, проверяемые за 30 секунд.
- **Честные минусы конвертируют** — блок «Важно знать» в каждой карточке (схема Airbnb
  «пространство / доступно гостю / важно знать»).
- **Мобайл ~50–70% трафика** — sticky-панель бронирования снизу (паттерн Airbnb/Booking).
- Фильтры при 2–5 квартирах не нужны — вместо них поиск по датам.
- Реквизиты ИП/самозанятого в футере — базовый сигнал легальности.

## Отложено (см. README «Что отложено»)

Онлайн-оплата, iCal-синхронизация с площадками, PDF-образцы договора/акта,
программа повторных гостей, «последнее бронирование N дней назад» (только на
реальных данных календаря — иначе дарк-паттерн).
