# У Максима — сайт посуточной аренды квартир

Статический сайт прямого бронирования: каталог квартир, живой календарь занятости,
мгновенный расчёт стоимости и заявка в WhatsApp/Telegram за 30 секунд. Без бэкенда,
без онлайн-оплаты — хостится бесплатно (GitHub Pages или любой статический хостинг).

## Структура

```
site/
  index.html   — главная страница (секции, тексты статических блоков)
  styles.css   — дизайн (менять не нужно)
  app.js       — логика: календарь, расчёт цены, бронирование (менять не нужно)
  data.js      — ⭐ ЕДИНСТВЕННЫЙ файл, который редактирует Максим
```

Открыть сайт локально: двойной клик по `site/index.html` — работает прямо из папки.

## Состояние контента

Квартиры, цены, описания, фото и отзывы — **реальные**, перенесены с профиля Авито
«Residents М5/М8» 11.08.2026 (10 объектов: М5 = 5-я Красноармейская 7, М8 = 8-я
Красноармейская 14, две студии в ЖК «Зенит», студия на Фонтанке, двушка на Савушкина).
Фото обработаны: водяной знак площадки убран, лежат в `site/photos/<id>/`.

## Что осталось заменить (всё в `site/data.js`)

1. **Контакты — ЕДИНСТВЕННОЕ КРИТИЧНОЕ** (блок `SITE`): `phone`, `phoneHref`,
   `whatsapp` (только цифры для wa.me), `telegram` (username без @), `email`.
   Сейчас стоят заглушки `+7 900 000-00-00` — заявки уходят в никуда.
2. **Занятость** (`busy` у каждой квартиры): сейчас пусто — сайт показывает всё
   свободным. Формат `['2026-08-20', '2026-08-23']` = заезд/выезд. Обновлять при
   каждой брони на любой площадке, иначе будут накладки дат.
3. **Тариф выходных** (`priceWeekend`): сейчас равен будничному (цена «от» с Авито).
   Если пт/сб дороже — прописать.
4. **Условия отмены, предоплаты и скидки за длительность**: спросить у Максима и
   вписать конкретику в FAQ; скидки — в `SITE.discounts` (сейчас пусто, не обещаем).
5. **ИНН** (`SITE.inn`): пока пусто — строка в футере скрыта автоматически.
   С реальным ИНН доверия больше.
6. **Фото Максима** в блоке «О хозяине»: в `index.html` найти комментарий
   `<!-- ЗАМЕНИТЬ -->` и поставить `<img class="host-photo-img" src="photos/maksim.jpg" alt="Максим">`.
7. **Яндекс.Метрика**: сниппет в `index.html`, номер счётчика — в `SITE.metrikaId`.
   Цели уже размечены: `booking_whatsapp`, `booking_telegram`, `booking_call` и др.

## Что уже встроено (по исследованию топовых сайтов)

- Поиск по датам на главной: гость выбирает даты — карточки показывают «свободна/занята» и точный итог за весь период.
- Календарь занятости в каждой карточке + расчёт: будни/выходные (ночи пт и сб — по тарифу выходного), доплата за доп. гостя, скидки от 7 ночей (10%) и от 30 (20%).
- Заявка одним кликом: WhatsApp — с готовым текстом (квартира, даты, гости, сумма); Telegram — текст копируется в буфер.
- Блоки доверия: «О хозяине», рейтинги площадок со ссылками, ответы хозяина на отзывы, реквизиты в футере.
- Отдельный блок для командировочных (чек, договор, акт) — незанятая ниша, у конкурентов этого нет.
- Мобильная версия со sticky-панелью бронирования, Schema.org-разметка, OG-теги.
