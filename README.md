# У Максима — сайт посуточной аренды квартир

Статический сайт прямого бронирования: каталог квартир, живой календарь занятости,
мгновенный расчёт стоимости и заявка в WhatsApp/Telegram за 30 секунд. Без бэкенда,
без онлайн-оплаты — хостится бесплатно (GitHub Pages или любой статический хостинг).

## Структура

```
site/
  index.html   — главная страница (секции, тексты статических блоков)
  styles.css   — дизайн (менять не нужно)
  app.js       — логика: календарь, расчёт цены, бронирование (менять не нужно)
  data.js      — ⭐ ЕДИНСТВЕННЫЙ файл, который редактирует Максим
```

Открыть сайт локально: двойной клик по `site/index.html` — работает прямо из папки.

## Что заменить перед запуском (всё в `site/data.js`)

Сейчас на сайте **демо-контент**. Перед публикацией заменить:

1. **Контакты** (блок `SITE` вверху файла): `phone`, `phoneHref`, `whatsapp`
   (только цифры, для ссылки wa.me), `telegram` (username без @), `email`.
2. **Реквизиты**: `legalStatus` (самозанятый / ИП) и `inn` — реальный ИНН.
   Это сигнал легальности, без него блок «Командировочным» не вызывает доверия.
3. **Квартиры** (массив `APARTMENTS`): названия, районы (адрес — БЕЗ номера дома,
   точный адрес сообщается после подтверждения брони), цены будни/выходные,
   описания, «Важно знать» (честные минусы — они повышают конверсию, не убирать!),
   удобства, фото.
4. **Фото**: сейчас — временные с Unsplash. Заменить на реальные снимки: положить
   файлы в `site/photos/квартира-1.jpg` и указать пути в `photos: ['photos/квартира-1.jpg', ...]`.
   Рекомендация из исследования: 15–20 фото на квартиру, первым — лучшее фото гостиной.
5. **Занятость** (`busy` у каждой квартиры): периоды `['заезд', 'выезд']` в формате
   `ГГГГ-ММ-ДД`. День выезда свободен для нового заезда. Обновлять при каждой брони
   на любой площадке — иначе будут накладки дат.
6. **Рейтинги площадок** (`platformRatings`): реальные цифры и ссылки на профили
   Авито/Суточно.ру. Выдуманные рейтинги работают в минус — только правда.
7. **Отзывы** (`REVIEWS`): реальные, с датой и площадкой. Поле `reply` — публичный
   ответ хозяина (сильный элемент доверия, заполнять по желанию).
8. **Фото Максима** в блоке «О хозяине»: в `index.html` найти комментарий
   `<!-- ЗАМЕНИТЬ: сюда реальное фото Максима -->` и поставить
   `<img class="host-photo-img" src="photos/maksim.jpg" alt="Максим">` вместо див-заглушки.
9. **Яндекс.Метрика**: завести счётчик, вставить сниппет в `index.html` (комментарий
   в `<head>` показывает куда), номер счётчика — в `SITE.metrikaId`. Цели уже
   размечены: `booking_whatsapp`, `booking_telegram`, `booking_call` и клики в шапке/футере.

## Что уже встроено (по исследованию топовых сайтов)

- Поиск по датам на главной: гость выбирает даты — карточки показывают «свободна/занята» и точный итог за весь период.
- Календарь занятости в каждой карточке + расчёт: будни/выходные (ночи пт и сб — по тарифу выходного), доплата за доп. гостя, скидки от 7 ночей (10%) и от 30 (20%).
- Заявка одним кликом: WhatsApp — с готовым текстом (квартира, даты, гости, сумма); Telegram — текст копируется в буфер.
- Блоки доверия: «О хозяине», рейтинги площадок со ссылками, ответы хозяина на отзывы, реквизиты в футере.
- Отдельный блок для командировочных (чек, договор, акт) — незанятая ниша, у конкурентов этого нет.
- Мобильная версия со sticky-панелью бронирования, Schema.org-разметка, OG-теги.

## Публикация на GitHub Pages (бесплатно)

```powershell
# один раз: создать репозиторий и включить Pages
gh repo create maksim-rent --public --source . --push
gh api repos/{owner}/maksim-rent/pages -X POST -f "source[branch]=master" -f "source[path]=/"
```

Сайт будет доступен по адресу `https://<owner>.github.io/maksim-rent/site/`.
Свой домен (например, `umaksima.ru`) подключается в настройках Pages.
